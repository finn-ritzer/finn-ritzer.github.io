# Meine Website

Persönliche Website, gehostet mit GitHub Pages.

## Was liegt wo?

| Datei / Ordner   | Wofür                                              |
|------------------|----------------------------------------------------|
| `index.html`     | Startseite mit Begrüßung und "Über mich"           |
| `projekte.html`  | Liste deiner Projekte                              |
| `kontakt.html`   | Kontaktwege, optional mit Formular                 |
| `404.html`       | Wird bei falschen Adressen angezeigt               |
| `style.css`      | Das komplette Design (Farben, Schriften, Layout)   |
| `script.js`      | Handy-Menü und automatische Jahreszahl             |
| `fonts/`         | Die Schriftdateien (lokal, ohne Google-Server)     |
| `images/`        | Bilder, z. B. dein Profilfoto                      |
